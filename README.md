# Mustaqeem Fareedi — Portfolio

A responsive, photo-free futuristic portfolio website built with plain HTML, CSS and JavaScript. No framework or coding setup is required to preview it.

## Preview on your computer
1. Extract the ZIP file.
2. Open the `mustaqeem-portfolio` folder.
3. Double-click `index.html` to open the website in Chrome.

## Publish it online with GitHub + Vercel
1. Create a GitHub account at https://github.com/ (if you don't have one).
2. Create a new **public repository** named `mustaqeem-portfolio`.
3. Upload the contents of this folder to the repository. Keep `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder at the repository's top level.
4. Create/sign in to Vercel at https://vercel.com/ and choose **Add New → Project**.
5. Import the `mustaqeem-portfolio` GitHub repository.
6. For a plain HTML site, leave the framework preset as **Other** and leave build/output settings empty unless Vercel asks otherwise. Click **Deploy**.
7. Vercel will give you a live `*.vercel.app` address. You can change the project name in Vercel settings if the name is available.
